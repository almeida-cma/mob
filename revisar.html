🧩 TÓPICO 1 · HTML, CSS e JavaScript — Os Três Pilares da Web

📖 O que você precisa saber

Todo aplicativo web ou mobile construído com tecnologias web usa três camadas com papéis bem definidos:

  • HTML (HyperText Markup Language): define a estrutura da interface — textos, títulos, botões, imagens, formulários. É o "esqueleto" da tela.
  • CSS (Cascading Style Sheets): cuida da aparência visual — cores, fontes, tamanhos, margens, bordas, espaçamentos, layout. É a "pele" da tela.
  • JavaScript: adiciona comportamento e interatividade — responde a cliques, valida formulários, altera o conteúdo em tempo real. É o "cérebro" da tela.
⚠️ Ponto de atenção: o JavaScript NÃO substitui HTML nem CSS. Ele trabalha junto, manipulando os elementos criados pelo HTML e estilizados pelo CSS.

🤖 TÓPICO 2 · Android e Dispositivos Móveis

📖 O que você precisa saber

  • Origem do Android: criado pela Android Inc. (2003), comprado pelo Google em 2005 e lançado comercialmente em 2008. É baseado no Kernel Linux.
  • Arquitetura em camadas: Kernel Linux → Camada de abstração de hardware (HAL) → Bibliotecas nativas + Android Runtime → Framework de aplicação → Aplicativos.
  • Dalvik → ART: a máquina virtual original do Android era a Dalvik; foi substituída pelo ART (Android Runtime), mais eficiente (compilação AOT).
  • Sensores: dispositivos móveis integram GPS, câmera, acelerômetro, giroscópio, bússola, sensor de proximidade, etc. Aplicativos podem (e devem) usá-los para enriquecer a experiência.
  • AndroidManifest.xml: arquivo de configuração que declara permissões, atividades e componentes do app.
⚠️ Ponto de atenção: é falso afirmar que dispositivos móveis não integram sensores. Eles são justamente um dos grandes diferenciais da plataforma móvel em relação ao desktop.

🌐 TÓPICO 3 · DOM e Interatividade com JavaScript

📖 O que você precisa saber

  • DOM (Document Object Model): é a representação em memória da estrutura da página. Cada elemento HTML vira um "nó" (objeto) que o JavaScript pode acessar.
  • Para que serve: permite ao JS localizar, ler, modificar e remover elementos da tela em tempo real — sem recarregar a página.
  • Exemplos práticos: mudar o texto de um botão, alterar uma cor, esconder uma seção, validar um formulário.
  • Métodos comuns: document.getElementById(), document.querySelector(), element.innerHTML, element.style, element.classList.
  • Propriedade .checked: booleana (true / false) usada para saber se um <input type="checkbox"> está marcado. Diferente de .value, que retorna o texto do campo.
⚠️ Ponto de atenção: não confunda .value (valor de texto de inputs) com .checked (estado de marcação de checkbox/radio).

📐 TÓPICO 4 · Planejamento de Projeto e Wireframe

📖 O que você precisa saber

  • Fase de planejamento: antes de programar, é essencial pensar na estrutura, no fluxo e na experiência do usuário.
  • Wireframe: esboço visual simples (geralmente em preto e branco) que mostra o layout e a hierarquia dos elementos da tela. Não tem cores nem detalhes finais.
  • Vantagens do wireframe:
    • Evita retrabalho de código.
    • Reduz custos e tempo.
    • Valida a ideia da interface antes de programar.
    • Ajuda a alinhar a equipe e o cliente.
  • Outros artefatos: storyboard (sequência de telas), protótipo (versão navegável), UI/UX (design de interface e experiência).
  • Low-code vs tradicional: plataformas visuais (App Inventor, Kodular, Thunkable) usam blocos de evento que correspondem, no código tradicional, a funções/manipuladores JavaScript (ex: onclick).
⚠️ Ponto de atenção: wireframe não é o código final. É um esboço de planejamento, feito antes da programação.

📡 TÓPICO 5 · Sensores e Agregação de Valor aos Apps

📖 O que você precisa saber

  • Sensores comuns: GPS (localização), câmera (fotos/leitura de códigos), acelerômetro (movimento), giroscópio (rotação), bússola (direção), sensor de proximidade, microfone.
  • Como agregam valor: conectam o app ao mundo físico do usuário, tornando a experiência mais rica, personalizada e funcional.
  • Exemplos práticos:
    • GPS → apps de entrega, mapas, corrida.
    • Câmera → leitura de QR Code, realidade aumentada, fotos.
    • Acelerômetro → contador de passos, jogos controlados por movimento.
    • Microfone → comandos de voz, gravação.
  • Permissões: para usar sensores, o app precisa declarar permissões no AndroidManifest.xml (ex: ACCESS_FINE_LOCATION para GPS).
⚠️ Ponto de atenção: a integração com sensores é um dos principais diferenciais dos apps móveis em relação a sites desktop.
